## 信息怎样理解

本文集使用三类表述：

1. **用户表达**：Berlin 自己说过的偏好、目标或计划。它能说明意图，不能证明功能已经实现。
2. **历史背景**：整理时可用的过往用户提供资料，主要涉及 2026 年 9—10 月。它不等于今天的项目状态；执行前需核对。
3. **整理建议**：为方便协作提出的方法和验收思路，尚未执行，也不冒充 Berlin 已经作出的决定。

各项目页列出的“建议下一步”不是新增的任务承诺，也不是上线、交易或付费授权。遇到新指示、实际代码或测试结果与这里冲突，应指出差异并更新相应事实。

## 这版没有收录什么

没有收录密码、私钥、账户凭证、服务器连接信息、财务账户、证件、健康资料、家庭私人信息或投诉材料。仓库私有也不适合存放这些内容；删除文件通常也不能消除 Git 历史中的副本。

这次新增内容放在 context/，原有 profile/、projects/、devices/、global/、skills/ 等文件保持不变。原有目录可能另有用途；本目录聚焦于可读的项目和学习背景，不能代替实时项目记录。

## 给后来接手的读者

先读相关项目页，不必把全部资料塞进每次任务。回答时说明哪些是已知背景、哪些是刚验证的事实，给出一个清晰的建议和可检查的下一步。尤其不要把“讨论过某个工具”写成“已安装”，把“回测不错”写成“已经稳定盈利”，或把“建了私有仓库”写成“所有 AI 已共享记忆”。
