### 通过资料复用减少跨工具重复解释
- 用户表达：希望 Codex、ChatGPT、Claude、Copilot、Kimi 等工具更了解他的背景。
- 当前边界：文档可以成为共同参考；上传文件并不证明各工具已建立连接、已经读取或会自动持续同步。
- 后续核实：具体工具是否有获准访问、能否读取最新版本、是否引用了正确资料。

### Obsidian 与 GitHub
- 用户表示：本地已经安装 Obsidian，并创建了仓库，对是否已同步到 GitHub 的描述带有不确定性。
- 本次已核实：BestBerlin/personal-context 是可访问的私有 GitHub 仓库，已有文件和提交。
- 尚未核实：本地 Obsidian 库与该远端的双向同步、冲突处理、离线编辑回传。
- 因而不能报告：“Obsidian、GitHub 和所有 AI 已经完全打通。”

## 更新方式

新的决定记录“做什么、为什么、适用范围、日期、何时重看”。项目进展记录“发生了什么、证据在哪、仍不确定什么”。不要为了让资料显得完整而补造结果。

遇到旧说法与新证据冲突时，保留必要的变更说明，并明确当前结论；不要在两篇文档里同时保留相互矛盾的现状。
