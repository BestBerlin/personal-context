# personal-context

个人长期背景资料，供各个 AI agent（Claude、Codex、Gemini 等）读取。

## 目录

- `profile/`：基本信息和偏好（怎么称呼、沟通风格、常用语言）
- `devices/`：设备概况（型号、用途、所在位置的大致描述）。**不写 IP、MAC、密码、密钥**
- `projects/`：各项目背景（目标、现状、注意事项）

## 规则

1. 仓库必须保持私有。
2. 不得写入任何密码、API Key、token、私钥、服务器地址。敏感信息放在密码管理器里，这里只写"去哪里取"。
3. 修改后提交到 Git，并保留提交记录。
4. 信息过时就更新或删除，不要留着错误内容。
